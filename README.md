# Touge

Гонки по горным дорогам Японии. Игра для Windows 10 и 11 (64-бит).

## Карта

Регион Канто в настоящих местах (масштаб 1:1,3): 45 горных перевалов — Акина (Харуна), Акаги, Ирохадзака, Усуй,
Мёги, Цукуба, Хаконе (Тёрнпайк, Нанамагари, кромка кальдеры), Ябицу, Фудзи (Субару-лайн, Адзами-лайн), Идзу (Амаги,
петлевой мост Кавадзу) и другие; скоростные шоссе между ними; Токио и Иокогама со скоростными дорогами Сюто, стоянки
PA Дайкоку, Тацуми, Ои, Радужный мост; побережье Сёнан от Одавары через Эносиму и Камакуру до Йокосуки и Иокогамы;
около 90 городов (Сайтама, Тиба, Хатиодзи, Кофу, Мито, Нарита, онсэн Икао и Кусацу и другие). Кнопка «Карта» — быстрый
переезд к перевалам и городам.

## Как запустить

1. Распакуй архив: правой кнопкой по файлу → «Извлечь всё». Прямо из архива игра не запустится.
2. В папке `Touge` запусти `Touge.exe`.
3. Windows может показать синее окно «Система Windows защитила ваш компьютер». Нажми «Подробнее», потом «Выполнить в любом случае». Так бывает с программами без платной подписи.

Если игра идёт рывками, в меню (Esc) выбери «Картинка: быстро» или качество «оптимальное».

## Игра вдвоём

Один игрок нажимает «Онлайн» → «Войти» → «Ссылка для друга» и отправляет ссылку второму.
Второй нажимает «Онлайн», вводит имя, вставляет ссылку в поле «Ссылка от друга» и нажимает «Войти».

## Управление

- W и S — газ и тормоз, A и D — руль, пробел — ручник
- R — вернуться на дорогу, B — вид камеры, L — фары
- Esc — меню (машина, перевал, гонка с ботами, качество графики)
- F11 — полный экран
